# Akada

**Free, offline practice questions for Nigerian senior secondary students (SS1–SS3).**

Akada is an Android app with over 9,000 multiple-choice questions across 16 subjects and 298 topics, with at least 30 questions per topic. Every answer comes with a short explanation. It works fully offline: no account, no sign-in and no data needed after you install it.

**Use it in your browser:** https://akada-me-d9de.vercel.app works on phones, tablets and computers, and can be installed to your home screen.

## Download and install (Android)

1. Open the [**latest release**](../../releases/latest) on your Android phone.
2. Under **Assets**, tap the file named `Akada-<version>.apk` to download it.
3. Open the downloaded file. If your phone asks, allow your browser or file manager to **install unknown apps** (Settings → Apps → Special access → Install unknown apps).
4. Tap **Install**, then open Akada.

To update, download the newer APK from the Releases page and install it over the old one. Your progress is kept.

> Akada is installed directly from GitHub, not from the Play Store, so Android shows a warning about apps from unknown sources. That's expected for apps installed this way.

## What's inside

- **16 subjects:** English Language, Mathematics, Further Mathematics, Physics, Chemistry, Biology, Agricultural Science, Geography, Computer Studies, Economics, Government, Commerce, Financial Accounting, CRS, Literature in English and History.
- **Topics by class:** every topic is labelled SS1, SS2 or SS3.
- **Practice:** 10 questions at a time, with instant feedback and an explanation. Questions you haven't answered yet come first.
- **Timed mock tests:** any of your subjects, 20 random questions each, scored as percentages.
- **Progress:** streaks, accuracy by subject, weak topics and bookmarks.
- **Light and dark themes.**
- **Gentle feedback:** subtle animations and short, quiet sounds (you can turn sounds off). Animations switch off when your device asks for reduced motion.
- **Screen reader support:** works with TalkBack on Android and with screen readers on the web.

Everything is stored on your phone. Akada sends nothing anywhere.

## About the questions

The questions are original practice questions written for Akada. They are **not past questions** from WAEC, NECO or any other examination body, and Akada is not affiliated with any of them. Calculation questions are generated by a script that computes the answers. If you find a mistake, please [open an issue](../../issues).

## For developers

The app is built with React Native and Expo (SDK 58) and lives in [`app/`](app).

```bash
cd app
npm install
npm start            # run in Expo Go on your phone
npm test             # unit and screen tests
```

- Questions are plain text in [`app/content/questions/`](app/content/questions). See the format at the top of [`app/scripts/build-questions.mjs`](app/scripts/build-questions.mjs).
- `npm run generate-questions` rewrites the calculation questions in `content/questions/generated/`.
- `npm run build-questions` checks every question and builds `src/data/questions.json`.
- **Releasing:** bump `version` (and `android.versionCode`) in `app/app.json`, commit, then push a tag such as `v1.0.1`. The [Android release workflow](.github/workflows/android-release.yml) runs the tests, builds the APK and attaches it to a GitHub Release.
